# DataProject1 – Titanic Dataset Exploration

This project explores the Titanic dataset using Python and Pandas.

## Objectives
- Practice reading CSV files with pandas
- Perform basic exploratory data analysis (EDA)
- Compute summary statistics
- Understand DataFrame operations

## Tools Used
- Python 3.14
- Pandas
- Jupyter Notebook
- Git & GitHub

## Dataset
The Titanic dataset contains passenger information such as:
- Age
- Sex
- Passenger class
- Survival outcome

Source: Kaggle Titanic Dataset

## Key Concepts Practiced
- `pd.read_csv()`
- `df.head()`
- `df.info()`
- Column selection
- Aggregations (`min()`, `max()`, `mean()`)
